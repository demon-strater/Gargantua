# Gargantua · Deep Space Observatory

Kerr 블랙홀을 실시간 광선 추적으로 관측하는 3D 탐사 사이트입니다. 청록색 계측 UI, 배경이 비치는 유리 스캔 패널, 크리에이티브 모드 방식의 자유 비행을 제공합니다.

## 실행

Node.js 22 권장. Windows PowerShell 실행 정책에 영향을 받지 않도록 `npm.cmd`를 사용해도 됩니다.

```sh
npm install
npm run dev       # http://127.0.0.1:8010 (점유 중이면 다음 포트)
npm run build     # TypeScript 검사 + dist/ 빌드
npm run preview
node scripts/verify-physics.mjs
```

## 관측 방법

- **자유 비행 시작** 또는 배경 클릭: 비행 시작. 마우스 드래그로 시선을 돌립니다(마우스 고정 없음). WASD 수평 이동, Space 상승, Shift 하강, Ctrl 가속.
- **Esc**: 열린 패널 닫기.
- **마우스 휠**: 시야각 24–85° 조절. **R**: 초기 관측 지점. **P**: 물리 패널. **H**: 조작 안내. **V**: 시네마틱 보기.
- **궤도 관찰**: 중심을 바라보며 천천히 공전. **시간 정지**: 가스 흐름·행성·관측 공전 일시 정지.
- **관측 지점**: 파노라마, 강착 원반, 광자 궤도, 사건의 지평선으로 이동합니다. 위치에 따라 스캔 패널이 자동으로 전환됩니다.
- **카메라 버튼**: 후처리까지 끝난 3D 관측 화면을 PNG로 저장합니다. UI는 포함하지 않습니다.
- **AUTO / ULTRA**: 성능 기반 자동 해상도와 최고 품질 전환.
- **모바일**: 조이스틱 이동, 화면 드래그 시선, ▲/▼ 높이, ≫ 가속.

## 시각적 구성

`space2`의 두 이미지는 백금색 안쪽 광륜, 주황색 바깥 원반, 미세한 가스 필라멘트의 참고 자료로 사용했습니다. 영상은 인디고색 난류 프리셋에 반영했습니다. 참고 이미지나 영상을 배경으로 붙이지 않고 장면을 셰이더에서 생성합니다. 원본 자료는 배포 파일에 복사하지 않았습니다.

- 데스크톱 4096×2048 / 모바일 2048×1024 절차적 원반 텍스처. 로그 반지름과 주기적 방위각으로 이음매를 피하고, 차등 회전과 두 위상의 교차 보간으로 가스 흐름을 만듭니다.
- 미세 필라멘트·난류 밀도·열점과 HDR 복사. 블룸은 밝은 영역에 집중하고 색수차와 필름 그레인은 낮춰 결을 보존합니다.
- 별과 은하수는 최종 광선 방향에서 조회하므로 중력 렌즈 효과를 함께 받습니다. 작은 행성도 동일한 광선 추적 안에서 교차 판정합니다.
- 스캔 패널의 배경 불투명도는 28–38%입니다. 테두리 뒤에 불투명한 면을 두지 않아 실제 3D 장면이 비칩니다.
- 가독성을 위해 조작 안내와 물리 패널은 조금 더 진하게 표시합니다. 작은 화면과 동작 감소 설정을 지원합니다.

## 물리 모델과 범위

기하 단위계 `G = c = M = 1`. `1 M = GM/c²`, 시간 단위는 `GM/c³`입니다. 기본 질량은 태양의 1억 배입니다.

- **Kerr 측지선**: 국소 비회전 관측자(ZAMO)의 광자 운동량에서 보존량 E, L, Q를 구합니다. 미노 시간의 분리된 운동 방정식을 속도 베를레로 수치 적분하고 각 스텝의 속도 크기를 불변량에 투영합니다.
- **사건의 지평선·ISCO·광자 궤도·에르고 경계**: 스핀에 따라 계산합니다. 비행 경계는 편구면 Boyer–Lindquist 좌표에서 `r₊ + 0.12 M`로 제한합니다. 스핀 편집 후에도 경계 검사를 적용합니다.
- **상대론적 복사**: 케플러 원궤도 가스와 ZAMO 카메라의 진동수비로 도플러 효과와 중력 적색편이를 계산합니다. RGB 흑체 색과 밝기는 근사입니다.
- **강착 원반**: 얇은 슬랩의 방출·흡수 모델. 반지름에 따른 온도 분포와 케플러 차등 회전을 사용합니다. 가스 난류는 절차적 텍스처이며 GRMHD(일반상대론적 자기유체역학) 해를 풀지는 않습니다. 고온 가스층은 선택적 체적 방출 근사입니다.
- **관측자의 이동**: 자유 비행은 장면 탐사를 위한 운동학적 카메라입니다. 우주선의 자유낙하·추력·가속도·속도에 따른 상대론적 수차까지 통합한 비행 시뮬레이터가 아닙니다. HUD의 시간 지연은 ZAMO 기준입니다.
- **행성과 시간**: 작은 행성의 기울어진 원궤도는 스케일감을 주는 근사입니다. 원반과 행성 시간은 화면 1초당 3 M으로 압축되어 흐릅니다. 실제 천체의 시간 척도는 패널에서 질량에 따라 환산합니다.

기본 **실제 물리** 프리셋은 a/M = 0.6, 도플러·적색편이 적용 상태입니다. **영화 연출**은 가시적 비대칭을 줄인 연출 설정이며, **인디고 난류**는 참고 영상에서 가져온 비물리적 색감입니다. 원반 형태와 빛의 경로는 3D에서 계산되지만, 영화 제작용 DNGR의 광선 다발 적분과 동일한 정확도는 아닙니다.

물리·영화 렌더링 참고: [James, von Tunzelmann, Franklin & Thorne (2015), Gravitational Lensing by Spinning Black Holes](https://arxiv.org/abs/1502.03808).

## 구조

- `src/shaders/blackhole.frag.glsl`: Kerr 광선 추적, 원반·가스·행성·별.
- `src/shaders/diskTexture.frag.glsl`: 시작 시 GPU에서 생성하는 난류 텍스처.
- `src/scene/FlightRig.tsx`: 자유 비행, 드래그 시선, 궤도 관찰, 줌.
- `src/scene/AdaptiveQuality.tsx`: FPS 기반 자동 품질 / ULTRA.
- `src/scene/ObservationCapture.tsx`: 완료된 프레임 저장.
- `src/ui/Overlay.tsx`, `ObservatoryControls.tsx`, `styles.css`: 관측 콘솔.
- `src/ui/ScanPopup.tsx`, `zones.ts`: 위치 기반 구조 스캔.
- `src/lib/kerr.ts`: 좌표 변환, 물리량, 비행 경계.
- `scripts/verify-physics.mjs`: 해석해, 좌표 왕복, 경계 보호, 영역 전환 회귀 검사.

## 검증과 배포

`npm run build`는 타입 검사와 정적 배포 빌드를 함께 실행합니다. 물리 검증 스크립트는 `.local/physics-check/`에 임시 모듈을 만들며 공개 파일에는 포함되지 않습니다. GLSL은 ES 3.0용 별도 컴파일러로 검사할 수 있습니다. GPU 드라이버와 실제 기기에서의 시각·성능 검증은 별도로 필요합니다.

Vite의 상대 경로 빌드를 사용하므로 GitHub Pages의 하위 경로에도 배포할 수 있습니다. 루트 `.github/workflows/pages.yml`은 이 프로젝트의 `dist/` 배포용입니다. `CODEX-WORKFLOW.md`가 가리키는 `astra-lab`은 별도 갤러리 프로젝트이므로, 그 홈페이지를 이 저장소의 이력으로 덮어쓰지 않습니다. 갤러리 배포 시에는 빌드 결과를 별도의 실험 하위 경로로 추가합니다.
